# 🗺️ SobesQuest — тренажёр собеседований

Онлайн-платформа для подготовки к собеседованиям: задачки по коду с автопроверкой,
теория и HR-вопросы, три уровня сложности (Junior → Middle → Senior), каталог компаний
с фирменными собеседованиями, карта-территория в личном кабинете, рейтинг игроков,
**форум для обсуждения задач** и админ-панель для управления контентом.

Интерфейс доступен на **русском и английском** языках (переключатель RU/EN в шапке).
Название легко поменять: правится в `src/i18n/ru.js` и `src/i18n/en.js` (ключи `brand1`, `brand2`).

## Стек

- **Фронтенд:** React 18 + Vite, react-router-dom, CodeMirror 6, framer-motion, lucide-react, собственный i18n (без библиотек)
- **Бэкенд:** Supabase (Postgres + Auth + Row Level Security)
- **Запуск кода задач:** прямо в браузере (Web Worker) — сервер для выполнения кода не нужен
- **Хостинг:** Vercel (статика, доступна 24/7)

## Локальный запуск

```bash
npm install
cp .env.example .env   # заполните ключами из Supabase
npm run dev            # http://localhost:5173
```

Без `.env` сайт работает в демо-режиме: главная страница и демо-задача доступны,
а страницы с базой показывают подсказку по настройке.

## Настройка Supabase (один раз)

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) и создайте проект (любое имя, регион — ближайший).
2. Откройте **SQL Editor → New query** и выполните по очереди четыре файла из `supabase/migrations/`:
   1. `001_schema.sql` — таблицы, роли, RLS-политики, рейтинг;
   2. `002_seed.sql` — контент: задачи, теория, компании, отзывы;
   3. `003_forum.sql` — таблица обсуждений задач (форум);
   4. `004_activity.sql` — дни активности игроков (стрики и теплокарта).
3. **Project Settings → API**: скопируйте `Project URL` и `anon public` ключ в `.env`:

   ```
   VITE_SUPABASE_URL=https://xxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJ...
   ```

4. Чтобы регистрация работала сразу без подтверждения почты: **Authentication → Sign In / Providers → Email** — выключите «Confirm email» (для продакшена лучше оставить включённым).
5. Зарегистрируйте свой аккаунт на сайте, затем сделайте себя админом — в SQL Editor выполните:

   ```sql
   update public.profiles set role = 'admin' where username = 'ВАШ_НИК';
   ```

   (или по email: `update public.profiles set role='admin' where id = (select id from auth.users where email='you@example.com');`)

Появится пункт «Админка» в меню: добавление/редактирование задач (условие, тесты, подсказки,
эталон, XP) и теоретических вопросов.

## Деплой на Vercel (онлайн 24/7)

### Вариант А — через интерфейс (проще)

1. Загрузите проект в репозиторий GitHub.
2. На [vercel.com](https://vercel.com) нажмите **Add New → Project** и импортируйте репозиторий.
3. В шаге **Environment Variables** добавьте `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` (те же значения, что в `.env`).
4. Нажмите **Deploy**. Через минуту сайт доступен по адресу `имя-проекта.vercel.app`.

### Вариант Б — через CLI

```bash
npm i -g vercel
vercel            # первый деплой: ответьте на вопросы
vercel --prod
vercel env add VITE_SUPABASE_URL        # вставьте значения, затем redeploy
vercel env add VITE_SUPABASE_ANON_KEY
vercel --prod
```

## Структура проекта

```
supabase/migrations/     SQL: схема, сид-контент, форум (выполняются в Supabase SQL Editor)
- **SQL-задачи** — решаются прямо в браузере через sql.js (SQLite / WASM)
src/
  i18n/                  словари интерфейса (ru.js, en.js)
  data/                  демо-задача и резервный каталог компаний
  lib/                   supabase-клиент, авторизация, i18n, раннер кода, прогрессия
  workers/               Web Worker: исполнение пользовательского кода + тесты
  pages/                 главная, задачи, компании, собеседование, кабинет, форум, рейтинг, админка
  components/            редактор, тесты, таймер, карта территории, обсуждения и др.
```

## Как это работает

- **Прогрессия:** задачи приносят XP; уровень считается пройденным при 70% решённых задач —
  тогда открывается следующий уровень и соответствующие компании.
- **Карта-территория:** тайлы расчищаются из «тумана войны» по мере решения задач;
  на карте появляются города уровней и офисы открытых компаний.
- **Стрики и активность:** в кабинете — огонёк «N дней подряд», рекорд и теплокарта
  активности за 10 недель; данные берутся из вида `activity_days` (решения, собеседования, комментарии).
- **Публичные профили:** `/players/:имя` — любой игрок виден по ссылке из рейтинга и форума:
  место в рейтинге, XP, стрик и теплокарта.
- **Черновики решений:** код в задаче автосохраняется в браузере и переживает перезагрузку;
  в собеседовании черновик подхватывается из практики.
- **Форум:** на странице каждой задачи — обсуждение; писать могут зарегистрированные игроки,
  читать — все. Сводка обсуждений — на странице «Форум».
- **Языки интерфейса:** RU/EN переключаются в шапке и запоминаются; контент (задачи, вопросы)
  хранится в БД на русском — для перевода контента добавьте поля с английскими текстами.
- **Безопасность:** RLS-политики — читать контент могут все, писать задачи только админы,
  свои результаты/отзывы/комментарии — только их владельцы; ключ anon публичный.
- **Бесконечный цикл в решении** не подвесит сайт: код исполняется в воркере с таймаутом 5 секунд.
